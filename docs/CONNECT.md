# 从第一次体验到管理自己的实例

## 只想看看效果

1. 打开 [ModelJetty 预览](https://modeljetty.16-146-69-101.sslip.io)。
2. 点击“免费体验”，等待显示“免费演示已连接”。
3. 在消息框输入 `你好，帮我确认连接成功`，点击“发送请求”。
4. 看到“免费模拟演示”“已收到”以及请求 ID，就完成了一次浏览器 → 服务器 → 浏览器的请求。

这是模拟回显，不是真实模型推理。记录只属于当前浏览器，15 分钟后过期；无需账号、管理令牌或付费 API Key。

## 管理本次部署的 EC2

网站右侧的“管理自己的实例”用于查看整个私有实例的统计及网站/App 联动。

**实例地址：** `https://modeljetty.16-146-69-101.sslip.io`

网页会自动填入当前地址，所以不需要编辑。App 的“网关地址”填写这个完整的 HTTPS 地址。当前网页固定连接同源 API；若管理另一台服务器，应打开那台服务器自己的网页。

**管理令牌：** 本次部署维护者在自己的 IDE 中打开 `.local/ec2-access.env`，找到 `ADMIN_TOKEN=`，只复制等号右侧的值。例如：

```dotenv
# 仅展示格式，这是假的示例令牌，不能登录。
ADMIN_TOKEN=demo-admin-token-example-1234
```

这个例子应该只填写 `demo-admin-token-example-1234`。实际连接必须换成私有文件中的真实值。该文件未提交到 GitHub，其他访客没有它；不要将真实令牌放进 Issue、截图或聊天。

点击“连接实例”，看到“网关已连接”后，再发送测试消息。另一个 App 或网页使用同一地址和管理令牌连接后，可以看到相同的私有请求记录。免费演示记录与这些记录隔离。

## 自己部署或本地开发

| 运行位置 | 地址例子 | 管理令牌来源 |
| --- | --- | --- |
| 自己的服务器 | `https://gateway.example.com`（替换为你的域名） | VM 安装器生成的服务器文件 `/etc/modeljetty/gateway.env`；通过已认证 SSH 读取 |
| 同一台电脑本地开发 | `http://localhost:8000` | 本地项目 `.env` 中的 `ADMIN_TOKEN` |
| 本项目线上免费演示 | 预览网站 → “免费体验” | 不需要令牌 |

`GATEWAY_TOKEN` 用于程序调用 `/v1/*`，不能用于管理台。AWS 账号密码、实例 ID、SSH 的 `.pem` 文件也不是这里的管理令牌。

如果显示 401，先检查复制的是对应服务器的 `ADMIN_TOKEN`，而不是本地开发令牌，再确认没有带上变量名、引号或多余空格。当前线上实例使用模拟模型；连接成功不代表已经配置真实模型供应商。
