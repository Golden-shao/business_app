- 现有实例：Amazon Linux 2023，t3.micro，913 MB 内存、8 GB 磁盘；没有调整规格或创建新计费资源。
- 当前公网 IP：`16.146.69.101`。入口：[HTTPS 预览](https://modeljetty.16-146-69-101.sslip.io)。临时 DNS 解析和可信证书已验证，HTTP 返回 HTTPS 跳转。
- 网关使用此前已审查合并的 `f556a6a32f4e6c80220ea342cf21c9c6947433e9`；该版本仍显示 Harbor。品牌与部署脚本更新通过正常 PR 审核后再发布，不把本地分支误报为已合并。
- 网站通过 Caddy 访问回环地址上的单进程网关。Redis 兼容 Valkey 仅监听 `127.0.0.1:6379`，网关仅监听 `127.0.0.1:8000`。
- 未认证管理请求返回 401；不同令牌分别验证 API completion 和管理台请求。Chrome 实际完成连接、发送模拟消息、显示回复与请求 ID，并看到 API / App 来源记录。
- 390px 移动布局无页面横向溢出，断开后令牌字段清空。
- 重启三个 systemd 服务后均恢复 active，已有请求记录保留，均已设置开机启动。未执行整机重启，因此不把 enabled 状态当作实际重启验收。
- 实测服务器约 547 MB 可用内存，三个服务内存约 3 MB / 44 MB / 11 MB；这是低负载瞬时数据，不是容量承诺。
- 模型是 mock，响应缓存关闭，没有付费模型调用。服务器凭据单独生成，未使用或上传开发机 `.env`。
- 浏览器验收一次失败诊断带出了管理令牌，随后已更换令牌并重启网关；之后的诊断先脱敏再输出。最终验收通过。

当前限制：单实例、单租户、可信测试者凭据接入，无匿名演示、用户注册、高可用或 K8s。不能把当前服务宣称为完成多用户产品或 Kubernetes 上线。
