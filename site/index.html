开始前，你可能想知道。

它和直接使用聊天工具有什么区别？

ModelJetty 面向正在开发 AI 应用的人：把模型调用集中到一个可自托管的入口，再通过同一份请求记录检查调用结果。它提供接入与诊断，回答能力来自你配置的模型。

现在可以真正调用我的模型吗？

自托管模式支持在服务端配置一个 OpenAI 兼容的模型服务，用非流式文本接口调用。当前公开演示只做模拟回显。真实模型 Key 不填在管理令牌框中，相关配置见部署文档。

可以直接用我的 ChatGPT 账号吗？

当前版本尚未接入“使用 ChatGPT 登录”，不能把 ChatGPT 登录凭据作为模型 API Key 填入。你可以先无需密钥体验模拟流程。

体验需要付费吗？

当前在线模拟演示不调用真实模型，无需账号或 API Key。自行接入模型服务可能产生供应商费用，自托管服务器也有其运行成本。项目采用 MIT 开源许可。
